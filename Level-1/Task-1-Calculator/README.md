# Simple Calculator

## Description

This project is a simple command-line calculator developed using Python.
It allows the user to perform basic arithmetic operations by selecting
an operation from the available menu.

## Features

- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Division by zero error handling
- Square root calculation
- Percentage calculation
- User-friendly command-line interface

## Operations Available

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Square Root
6. Percentage Calculation

## Technologies Used

- Python 3
- Python `random` module is not required for this task
- Python built-in functions and operators

## How to Run

1. Make sure Python 3 is installed on your system.
2. Download or clone this repository.
3. Open the `Task-1-Calculator` folder in a terminal.
4. Run the following command:
