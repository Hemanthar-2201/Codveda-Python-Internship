# Number Guessing Game

## Description

This project is a simple command-line number guessing game developed
using Python.

The game allows the user to select a difficulty level. Based on the
selected level, the program generates a random number within a specific
range and gives the user a limited number of attempts to guess it.

## Difficulty Levels

- Easy: Number between 1 and 10 — 5 attempts
- Moderate: Number between 1 and 50 — 7 attempts
- Hard: Number between 1 and 100 — 9 attempts

## Features

- Three difficulty levels
- Random number generation
- Limited number of attempts
- "Too high" and "Too low" feedback
- Correct guess detection
- Game-over message after all attempts are used
- Displays the correct number when the player loses

## Technologies Used

- Python 3
- Random module
